# Changelog

## 0.2.2 (2026-10-05)

- The confirmation prompt now appears when the server comes from this plugin. Earlier versions did not show it. It now also covers `update_ad`, `register_webhook`, and `unregister_webhook`.
- The `insights-analyst` agent now starts when the server comes from this plugin.

To update, run `claude plugin marketplace update ayrshare`, then `claude plugin update ayrshare@ayrshare`, and restart Claude Code.
